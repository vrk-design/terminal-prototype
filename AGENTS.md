# AGENTS.md

Instructions for the coding agent. Read this at the start of every new thread.

## Task Log

- A `tasks_log/` folder exists in the repo root.
- For **every task** the user gives, create a separate markdown file there named `task_name-YYYY-MM-DD.md` (lowercase, spaces → underscores; use the date the task was completed).
- The log file must follow this structure:

  1. **Task** — describe the task as given (plus any clarifying context).
  2. **Process** — step-by-step account: for each step, which tool calls were made and what the end result was.
  3. **Mistakes** — separately list any mistakes made along the way and the reason for each. Write "None" if there were none.
  4. **Faster next time** — separately describe how the task could be done faster/more efficiently given what was learned.

- Write the log file as the final step of the task, after the work is done and validated.
